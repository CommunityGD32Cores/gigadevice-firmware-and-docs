  This demo is based on the GD32150R-EVAL-V1.3 board, it shows how to 
configure the CRC module. In this demo, 9 CRC codes are calculated for a 32-bit
data , the data can input with byte, half word and word(this chip can support these data style
input).

  If the test passes, will turn on the LED1, LED2 and LED3.
